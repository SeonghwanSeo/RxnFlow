# Reference implementation deviations — 2026-10-02

This audit corrects the earlier claim that the current policy/model implementation followed the reference execution structure. Sharing matrix multiplication and a TB objective did not preserve candidate representation,normalizer estimation,exploration or the graph architecture. The current version/hsx implementation is the audit target;“RxnFlow” below means this repository's master branch,not the current working branch. This is a source comparison of the forward-policy/subsampling/model/training/rollout paths,not a proof of complete numerical equivalence across every repository file. The initial audit preceded the implementation changes; the restoration status below records the subsequent authorized fixes.

## Corrections to earlier descriptions

“CGFlow-style common sampling” was too broad. In the checked CGFlow source,sample() iterates protocols and sample_protocol() draws each library in that protocol. A library appearing under multiple protocols can therefore be drawn multiple times. The current implementation shares one draw per library across all needed protocols. The user explicitly requested library-level common sampling,so retaining that behavior is justified,but it is not an exact copy of CGFlow's sample lifetime.

CGFlow also reduces linker sampling ratios by its linker/brick library-count coefficient;the current uniform per-library ratio0.01 follows the user's current configuration and repository requirement. Do not restore this coefficient silently. HSX explore sampling is tier/cluster-stratified,and HSX main uses hierarchical action clustering;neither is the requested uniform library sampler.

Current fp/property separate projections match the broad HSX explore pattern;they are not simply the earlier direct-fingerprint/property concat. Current action-embedding normalization and bounded temperature follow HSX main SimilarityMDP(dot). MSE TB,scalar logZ,its separate learning rate,EMA and FIFO replay have reference precedents;they must not be described as unsupported inventions merely because different references choose different defaults.

Backward depth weights sum(num_total_actions**(-depth)) are directly present in RxnFlow master calc_bck_logprob. They are not an independently invented heuristic. Matching both action and parent SMILES,depth-bounded synthon-compatible enumeration,and forward checks adapt that search to the current state definition. Removal of the arbitrary two-result cutoff and global shortest-route pruning addressed the previously authorized completeness review. Exact state-depth semantics and chemistry/property-budget limitations remain documented separately.

Removing workflow/Stop,using oriented brick/linker synthons and Enamine artifacts,local injectable rewards,native Torch without PyG,fixed max_atoms padding,uniform per-library subsampling and excluding external docking/services are established requirements. These should not be reverted while correcting unrequested policy/model changes.

## Correction order

First restore reference masked-logit representation,observed-action scoring and subsampling/normalizer semantics as one coherent policy change. Then align device-side sampling,reference exploration weighting,and protocol-level matrix grouping. Restore reverse/model overlap next. Treat graph architecture,feature preservation and initialization as an explicit baseline-fidelity correction,not a throughput tweak. Compare outputs/probabilities/gradients where mathematics should match before rerunning timing. A passing training run alone is not evidence of equivalence.

## Restoration implemented — 2026-10-02

All nine rows above have been addressed. `ProtocolLogits` retains `[state, sampled block]` matrices and their boolean masks; candidate `nonzero`/ragged packing and observed-action forced inclusion are removed. Each library is drawn once per policy call. Blocks are encoded together and compatible libraries are concatenated for protocol-level matrix products. Observed action logits use a separate numerator pass; denominator weights are the original uniform inclusion correction and logP is clamped at zero. Sampling and Gumbel noise stay on the model device. Random rows use CGFlow's library/protocol offsets, followed by the same property masks. Only chosen indices are decoded into `RxnAction` objects.

Reverse results are collected after the next forward-policy computation, before submitting child searches. Terminal/final pending results are explicitly drained. The generated parent tree and matching backward probabilities are retained; reverse chemistry/route weighting are unchanged by this scheduling correction.

The state encoder now uses native-Torch GENConv(add) and TransformerConv equations: incoming messages `ReLU(x_j + e_ji) + 1e-7`, head-concatenated attention with edge contributions to both keys and values, root skip, graph-mode non-affine normalization, conditional scale/shift, virtual edges and incoming-mean self-loop features. Each attention head has H channels. Readout is molecular mean concatenated with virtual node (2H), followed by HSX explore's state LayerNorm. Explicit source-equation tests compare outputs and all input/parameter gradients in float64. No graph/scatter dependency was added. Fixed graph capacity and synthon feature/condition definitions remain environment-specific.

Atom chirality is restored. HSX explore graph/SiLU MLP initialization, block_dim64, policy MLP depth2 and block MLP depth1 are explicit; graph width128/layers3/heads4 retain this project's configured scale. Fingerprint/property projection and type fusion remain separate, with price tiers excluded. Main-branch SimilarityMDP(dot) action normalization and bounded temperature remain. UniReaction's learned scalar choice, scalar logZ, no workflow/Stop, shared library draws and uniform ratios are intentional adaptations, not assertions of a byte-for-byte model port. A fully masked sampled action space still yields a failed rollout without refilling; training uses a finite denominator floor for such rows before the reference logP clamp.

Old checkpoint weights are incompatible with the restored graph/head shapes; no migration or alternate model path was added. Prepared artifacts and chemistry remain unchanged. Global device RNG now drives categorical draws, and evaluation isolates it from training with `fork_rng`; checkpoint continuation includes CPU/CUDA RNG state.
